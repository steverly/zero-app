Politique de confidentialité

Dernière mise à jour : 29 mai 2026

1. Qui sommes-nous ?

Zero est une application mobile développée par l'équipe Zero. Pour toute question : contact@zero-app.fr

2. Données collectées

Nous collectons uniquement les données nécessaires au bon fonctionnement de l'application :

  • Les messages que vous envoyez à Zero (traités en temps réel, non stockés de façon permanente)
  • Les informations d'abonnement via RevenueCat (identifiant anonyme, statut d'abonnement)
  • Les données publicitaires via AdMob (identifiant publicitaire anonymisé)

3. Utilisation des données

Vos données sont utilisées exclusivement pour :

  • Générer les réponses de Zero via notre IA
  • Gérer votre abonnement Premium
  • Afficher des publicités pertinentes (version gratuite)

4. Partage des données

Nous ne vendons jamais vos données. Elles peuvent être partagées uniquement avec nos prestataires techniques (OpenAI, RevenueCat, Google AdMob) dans le cadre de leurs propres politiques de confidentialité.

5. Conservation

L'historique de conversation est conservé localement sur votre appareil pendant 20 minutes, puis effacé automatiquement.

6. Vos droits

Vous pouvez à tout moment demander la suppression de vos données en nous contactant à contact@zero-app.fr.

7. Contact

Équipe Zero – contact@zero-app.fr
